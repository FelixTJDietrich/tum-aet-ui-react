# Theming

## Dark mode

Set `data-theme="dark"` on `<html>` to use the dark theme and remove it (or set `light`) to go back. The theme also sets the matching CSS `color-scheme`. Use the toolbar of this Storybook to switch.

```ts
document.documentElement.dataset.theme = 'dark';
```

## Overriding tokens

The defaults live in a low-priority cascade layer. Override a custom property in an unlayered stylesheet on the document element; components and popups inherit it. Supply a light and a dark value when you change colours.

```css
:root,
[data-theme='light'] {
  --tumaet-ui-primary-color: #0065bd;
}
[data-theme='dark'] {
  --tumaet-ui-primary-color: #64a0c8;
}
```

## Tokens

| Group          | Custom properties                                                                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spacing        | `--tumaet-ui-spacing` (0.25rem; components use multiples)                                                                                                                                                  |
| Type           | `--tumaet-ui-font-family`, `--tumaet-ui-font-size-{xs,sm,base,lg,xl}`, `--tumaet-ui-line-height-*`                                                                                                         |
| Shape          | `--tumaet-ui-radius-{sm,md,xl,2xl}`                                                                                                                                                                        |
| Elevation      | `--tumaet-ui-shadow-{xs,sm,md,lg,xl}`                                                                                                                                                                      |
| Brand          | `--tumaet-ui-primary-color`, `--tumaet-ui-primary-contrast-color`, `--tumaet-ui-accent-color`, `--tumaet-ui-focus-color`                                                                                   |
| Text           | `--tumaet-ui-text-color`, `--tumaet-ui-text-hover-color`, `--tumaet-ui-muted-color`, `--tumaet-ui-disabled-color`                                                                                          |
| Backgrounds    | `--tumaet-ui-content-background`, `--tumaet-ui-control-background`, `--tumaet-ui-overlay-background`, `--tumaet-ui-hover-background`, `--tumaet-ui-disabled-background`, `--tumaet-ui-contrast-background` |
| Borders        | `--tumaet-ui-border-color`, `--tumaet-ui-control-border-color`, `--tumaet-ui-control-border-hover-color`                                                                                                   |
| Highlight      | `--tumaet-ui-highlight-color`, `--tumaet-ui-highlight-background`, `--tumaet-ui-highlight-focus-background`                                                                                                |
| States         | `--tumaet-ui-state-{danger,success,warning,info}`, with `-contrast` and `-foreground` variants                                                                                                             |
| Table, tooltip | `--tumaet-ui-table-striped-background`, `--tumaet-ui-tooltip-background`, `--tumaet-ui-tooltip-color`                                                                                                      |

The full list with the light and dark values is in `src/styles/themes.css`.

When you change a colour, check the contrast: text needs 4.5:1 and interface parts such as borders and focus rings need 3:1 against their background, in both themes.
